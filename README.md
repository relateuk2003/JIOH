# Janice Is On Holiday

A first-person game about preparing paperwork in an empty office, played over fourteen real days. Godot 4.5, Compatibility renderer (JIOH-42).

Tickets live in Jira under the JIOH project. Commits and PRs name the ticket they close.

## Layout

| Path | What |
| --- | --- |
| `autoload/world_clock.gd` | The only source of time (JIOH-14). Nothing else may call `Time.get_*`. |
| `autoload/campaign_state.gd` | The fourteen-day calendar stamped at New Game (JIOH-15). |
| `autoload/day_phase.gd` | Closed / pre-open / handout / working / cutoff / wind-down (JIOH-16). |
| `autoload/document_registry.gd` | Every document template by `doc_id` (JIOH-18). |
| `autoload/render_config.gd` | Applies the PS1 look from `resources/environment/ps1_master_shipped.tres` (JIOH-59). |
| `autoload/interaction_manager.gd` | The five verbs, the single carry slot and the interaction event stream (JIOH-50). |
| `autoload/object_registry.gd` | Where you left it is where it is (JIOH-54). |
| `scenes/rendering/render_stack.tscn` | Main scene: the 320x240 internal viewport and integer upscale (JIOH-44). |
| `scenes/office/office_blockout.tscn` | Grey-box office, generated by `tools/build_office_blockout.gd` (JIOH-43). |
| `scenes/levels/office_level.tscn` | The playable office: building, player, lights, `Props`. |
| `scenes/player/player.tscn` | First-person controller; tune `resources/player/movement_profile.tres` (JIOH-46). |
| `shaders/` | PS1 base material (snap, affine), dither and quantise post pass. |
| `resources/campaign/day_schedule.tres` | Phase boundaries. Tune here, not in code. |
| `resources/documents/templates/` | One `.tres` per document type. Drop one in and it registers. |
| `scripts/documents/` | `DocumentInstance` and its signature and stamp marks. |
| `tools/debug/` | Time console and fortnight soak. Debug builds only; excluded from release exports. |
| `addons/document_inspector/` | Editor dock listing every template and its fields. Enable it in Project Settings → Plugins. |

## Building

`build/build.sh` exports Windows and Linux (the gates) and macOS into
`build/out/janice-<version>-<platform>.zip`, with the version from
`git describe` baked into the game (shown on the pause screen; `janice -- --print-build`
prints it). `build/build.sh --release` refuses a dirty tree and appends
`build/CHANGELOG.md`. Set `GODOT` to the Godot 4.5.1 binary; the 4.5.1 export
templates must be installed. `tests/build/run_build_tests.sh` checks the whole
pipeline (slow, so not in `tests/run_all.sh`). JIOH-60.

## Controls

WASD or arrows to walk, mouse to look, left click or E to use (pick up, place, insert, open), right click or Q to examine, Ctrl to crouch, Esc to free the mouse. There is no sprint.

## Debug tools (debug builds only)

- Backtick: time console. `goto 11 wind_down`, `skip 2h`, `freeze`, `thaw`, `rate 60`, `now`, `reset`.
- F3: render panel. Toggle snapping, affine, dither and fog; slide the grid, colour levels and fog density; restore the shipped preset.

## Saves

Autosave only, to `user://saves/slot_1/campaign.sav` (JIOH-36). There is no save button by design. Delete that folder to start fresh.

## Tests

Probes follow the OTIF pattern: each is a scene under `tests/` that prints `PROBE OK` / `PROBE FAIL` and exits non-zero on failure.

```sh
GODOT=/path/to/godot tests/run_all.sh                                    # everything
godot --headless --path . res://tests/DayPhaseProbe.tscn                  # one probe
godot --headless --path . --script res://tools/debug/soak_fortnight.gd    # the fortnight soak
tools/check_time_calls.sh                                                 # no OS clock reads outside WorldClock
godot --headless --path . --script res://tools/validate_persistent_ids.gd # no blank or duplicate persistent ids
```

Probes under `tests/gpu/` render real frames, so they need a display; `run_all.sh` uses `xvfb-run` when there is none. Physics probes should run with `--fixed-fps 60`, which `run_all.sh` does.

```sh
JIOH_UPDATE_REFERENCE=1 godot --path . res://tests/gpu/ShippedLookProbe.tscn  # after a deliberate change to the look
```
